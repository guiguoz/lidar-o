Lidar’O — Guide de démarrage

Ce guide est destiné aux utilisateurs qui n’ont pas de connaissance de Python ni du terminal. Il couvre l’installation, la première utilisation, la configuration des dossiers, et la désinstallation.

A — Prérequis système

ÉlémentMinimumRecommandé
SystèmeWindows 10 (64 bits)Windows 11
RAM8 Go16 Go ou plus
Disque libre20 Go50 Go ou plus
CPU4 cœurs8 cœurs
InternetPour télécharger les données LiDAR et BD TOPO—
Données nécessaires avant de commencer :
  • Dalles LiDAR HD .copc.laz de votre zone (disponibles gratuitement sur IGN Géoplateforme)
  • BD TOPO de votre département, fichier .gpkg (même source, France uniquement)
  • Coordonnées de l’emprise de votre terrain (en Lambert-93 de préférence)

B — Installation (une seule fois)

  1. Extrayez l’archive téléchargée (ex. LidarO-v0.4.0-Windows-x64.zip) dans un dossier de votre choix.
    Conseil : utilisez un chemin court sans accents ni espaces, par exemple C:\LidarO\.
  2. Double-cliquez sur setup.bat.
    Une fenêtre s’ouvre et affiche la progression. L’opération dure 2 à 5 minutes selon la vitesse du disque.
    Attendez le message : « Installation terminée » avant de fermer la fenêtre.
  3. Pour vérifier que tout est en ordre, double-cliquez sur LidarO_diagnostic.bat.
    Toutes les lignes doivent afficher [OK]. En cas d’erreur, relancez setup.bat.
Ne déplacez pas le dossier après l’installation. L’environnement Python est lié au chemin d’installation. Si vous devez déplacer Lidar’O, supprimez le sous-dossier python\ et relancez setup.bat.

C — Premier lancement

Double-cliquez sur LidarO.bat. L’interface graphique s’ouvre.

Au premier lancement, Lidar’O crée automatiquement un fichier de configuration dans :

%APPDATA%\LidarO\config.yaml

(Chemin complet typique : C:\Users\VotreNom\AppData\Roaming\LidarO\config.yaml)

Ce fichier de configuration est conservé lors des mises à jour de l’application. Vous ne perdrez pas vos paramètres en réinstallant.

D — Dossier des résultats

Par défaut, les résultats (fichiers .omap, journaux, rasters intermédiaires) sont écrits dans le sous-dossier output\ du dossier d’installation.

Si vous installez Lidar’O dans un dossier protégé (par exemple C:\Program Files\), le dossier output\ sera inaccessible en écriture sans droits administrateur. Configurez plutôt un dossier de sortie dans vos documents (voir ci-dessous).

Configurer un dossier de sortie personnalisé

Ouvrez %APPDATA%\LidarO\config.yaml avec le Bloc-notes et ajoutez ou modifiez la ligne :

output_dir_root: "C:/Users/VotreNom/Documents/LidarO_sorties"

Utilisez des slashes (/) même sous Windows. Le dossier sera créé automatiquement.

Vous pouvez aussi définir cette variable une fois pour toutes via :

LIDAR_OUTPUT_ROOT=C:\Users\VotreNom\Documents\LidarO_sorties

dans les variables d’environnement de Windows (Panneau de configuration → Système → Variables d’environnement).

E — Préparer un projet

Télécharger les données LiDAR

  1. Allez sur geoplateforme.ign.fr → onglet Téléchargement → LiDAR HD.
  2. Sélectionnez votre zone, téléchargez les dalles au format .copc.laz.
  3. Placez-les dans un dossier dédié, par exemple C:\Donnees\MonTerrain\laz\.

Télécharger la BD TOPO

  1. Sur la même plateforme IGN → BD TOPO → sélectionnez votre département.
  2. Téléchargez le fichier .gpkg (format GeoPackage).
  3. Placez-le dans un dossier data\bdtopo\ (configurable dans config.yaml).

F — Interface graphique

L’interface principale propose :

  • Terrain : sélectionner ou créer un terrain depuis la liste.
  • Moteur végétation : supervised_e (modèle pré-entraîné, recommandé) ou kp (interprétation directe KP).
  • Mode export (supervised_e uniquement) :
    • faithful — export fidèle, polygones tels quels (défaut)
    • smoothed — frontières communes arrondies (σ = 1,5 m) ; même modèle que faithful, contours adoucis
    • generalized — polygones simplifiés (MMU + lissage cartographique)
  • Lancer : démarre le calcul. La progression s’affiche dans la zone de log en bas de fenêtre.

Le calcul peut durer de quelques minutes à plus d’une heure selon la surface et la puissance de la machine.

G — Résultats

À la fin du calcul, le fichier MonTerrain.omap est disponible dans le dossier de sortie configuré.

Ouvrez-le avec OpenOrienteering Mapper (OOM), disponible gratuitement.

Contenu typique d’une carte : courbes de niveau, routes, bâtiments, hydrographie et végétation par classes d’ouverture forestière. Les fichiers intermédiaires (pipeline.log, run_metadata.json) restent disponibles pour le diagnostic.

H — Mise à jour

Procédure

  1. Sauvegardez votre ancien dossier d’installation si vous souhaitez pouvoir revenir en arrière (renommez-le, par exemple LidarO-v0.1.0-Windows-x64-old).
  2. Extrayez la nouvelle archive dans un nouveau dossier.
    Ne pas extraire par-dessus l’ancien : les deux versions doivent coexister dans des dossiers séparés.
  3. Double-cliquez setup.bat dans le nouveau dossier pour initialiser l’environnement Python.
    Si la version du runtime n’a pas changé, l’extraction est ignorée automatiquement.
  4. Lancez LidarO.bat depuis le nouveau dossier.

Ce qui est préservé

  • Vos paramètres (%APPDATA%\LidarO\config.yaml) sont conservés entre les versions. La nouvelle installation ne les écrase pas.
  • Vos résultats sont préservés uniquement s’ils se trouvent en dehors du dossier d’installation (voir section D). Si output_dir_root n’est pas configuré, les sorties sont dans output\ à l’intérieur du dossier d’installation et ne seront pas copiées automatiquement.
  • Vos données LiDAR et BD TOPO doivent se trouver hors du dossier d’installation pour ne pas avoir à les déplacer à chaque mise à jour.
Mise à jour non automatique. Il n’y a pas de mécanisme de mise à jour automatique. Vérifiez manuellement la disponibilité d’une nouvelle version.

I — Désinstallation

Désinstallation de l’application

Supprimez simplement le dossier d’installation (ex. C:\LidarO\). Aucun désinstallateur nécessaire, aucune entrée dans le registre Windows.

Vos projets et résultats

Les fichiers de résultats (.omap, journaux) sont préservés uniquement s’ils se trouvent en dehors du dossier d’installation. Si vous n’avez pas configuré output_dir_root, les sorties sont dans le sous-dossier output\ du dossier d’installation et seront supprimées avec l’application.

Préférences utilisateur (optionnel)

Le fichier %APPDATA%\LidarO\config.yaml est conservé lors de la désinstallation. Pour le supprimer :

%APPDATA%\LidarO\

Ouvrez ce chemin dans l’Explorateur Windows et supprimez le dossier LidarO.

LidarO_diagnostic.bat affiche installation en cours ou interrompue setup.bat en cours d’exécution, ou interrompu Attendre la fin, ou relancer setup.bat si la fenêtre est fermée

Erreur d’écriture dans le dossier de sortie Dossier en lecture seule ou droits insuffisants Configurer output_dir_root vers un dossier dans vos Documents

Journal de support : le fichier pipeline.log dans le dossier de sortie du terrain contient le détail complet du dernier calcul. Joignez-le à tout rapport de problème.
